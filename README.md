# Anvil — Open-Source FPGA CLI Tool

Command-line tool for synthesizing and programming FPGAs using the open-source F4PGA toolchain (Yosys + VPR). Designed for use on Windows via WSL2.

---

## Installation

Copy files to `/home/<user>/opt/anvil/`:

```bash
mkdir -p ~/opt/anvil/xdc
cp anvil.py     ~/opt/anvil/anvil.py
cp boards.json  ~/opt/anvil/boards.json
cp xdc/*.xdc    ~/opt/anvil/xdc/
chmod +x ~/opt/anvil/anvil.py
```

Add to PATH by adding this to `~/.bashrc`:

```bash
echo 'alias anvil="python3 ~/opt/anvil/anvil.py"' >> ~/.bashrc
source ~/.bashrc
```

Verify:

```bash
anvil --help
```

## Directory structure

```
~/opt/anvil/
├── anvil.py                     ← CLI tool
├── boards.json                  ← Board registry
└── xdc/
    └── Nexys-A7-100T-Master.xdc ← Pin constraints per board
```

Per project (generated by `anvil init`):

```
my_project/
├── config.json     ← Board config (auto-generated)
├── top.v           ← Your Verilog design
├── my_project.xdc  ← Pin constraints (copied from board master)
├── Makefile        ← Auto-generated
└── common/
    └── common.mk   ← F4PGA build rules
```

## Commands

### `anvil boards`
List all supported boards.

```
$ anvil boards
[Anvil] Supported boards:
  Nexys-A7-100T        Digilent Nexys A7 100T (xc7a100t)
```

---

### `anvil init --board <name>`
Initialize a new project in the current folder for the specified board.

```bash
mkdir my_project && cd my_project
anvil init --board Nexys-A7-100T
```

Creates:
- `config.json` — stores board settings used by compile/program
- `top.v` — minimal Verilog skeleton
- `my_project.xdc` — full pin constraints copied from board master XDC
- `Makefile` + `common/common.mk`

> **Note:** The XDC file contains all board pins. Comment out the ones you don't use in your design.

---

### `anvil compile`
Synthesize and generate a bitstream. Reads board settings from `config.json`.

```bash
anvil compile
```

Output bitstream is saved to `build/<target>/top.bit`.

Typical times on WSL2 (Nexys A7 100T):
- Simple combinational design: ~20 seconds
- PicoSoC demo: ~5 minutes

---

### `anvil program`
Upload the bitstream to the connected board.

```bash
anvil program
```

**Before running on Windows/WSL2:**

1. Connect Nexys A7 via USB
2. In PowerShell (admin):
   ```powershell
   usbipd list                       # find Nexys (0403:6010)
   usbipd bind --busid <BUSID>
   usbipd attach --wsl --busid <BUSID>
   ```
3. Run `anvil program` in WSL

> **Note:** The board power switch must be ON.
> Re-run `usbipd attach` after each replug or power cycle.

---

### `anvil clean`
Remove the `build/` directory.

```bash
anvil clean
```

## Typical workflow

```bash
# 1. Create project
mkdir blinky && cd blinky
anvil init --board Nexys-A7-100T

# 2. Edit your design
nano top.v

# 3. Edit pin constraints (comment out unused pins)
nano blinky.xdc

# 4. Build
anvil compile

# 5. Attach USB (PowerShell admin on Windows)
#    usbipd attach --wsl --busid <BUSID>

# 6. Program
anvil program

# 7. Clean if needed
anvil clean
```

## Adding a new board

1. Add an entry to `~/opt/anvil/boards.json`:
   ```json
   "Arty-A7-100T": {
     "description": "Digilent Arty A7 100T",
     "target":    "arty_100",
     "partname":  "xc7a100tcsg324-1",
     "device":    "artix7",
     "ofl_board": "arty_a7_100t",
     "xdc":       "Arty-A7-100T-Master.xdc"
   }
   ```

2. Add the corresponding XDC file to `~/opt/anvil/xdc/Arty-A7-100T-Master.xdc`

3. Verify with `anvil boards`

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `No config.json found` | Run `anvil init --board <name>` first |
| `ValueError: max() arg is an empty sequence` | XDC has no active pin constraints — uncomment the pins you use |
| `Error: no device found` | Board not powered on, or USB not attached via usbipd |
| `symbiflow_synth: not found` | Conda env not activated — check F4PGA installation |
| BUSID changed after replug | Run `usbipd list` and `usbipd attach` with new BUSID |
| Clock SDC error | Remove `create_clock` from XDC if your design has no clock port |
